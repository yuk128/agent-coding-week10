# RETRO — 5분 회고 (비난 없는 회고)

| 질문 | 팀 답 |
|---|---|
| 가장 놀랐던 공격 한 가지 (그리고 왜 통했나) | 전각 문자·제로폭 문자 등을 이용한 난독화 공격. 눈으로 보기에는 정상적인 문장처럼 보여도 탐지 로직을 우회할 수 있다는 점이 인상적이었다. |

| AI 가 쓴 방어 중 허점이 있던 것 | CI 코드에서 실제 프로젝트에 없는 파일 경로를 사용해 실행 오류가 발생했다. |

| 방어를 추가하다 정상 요청을 막은 경험 | 정상 요청도 함께 테스트하여 악성 입력 차단과 정상 입력 허용을 구분했다. |

| 다음에는 처음부터 하겠다고 정한 것 (시프트 레프트) | 코드 작성 전 파일 구조와 보안 요구사항을 먼저 확인하고, 개발 초기부터 보안 테스트를 진행한다. |

| 팀 협업에서 잘된 점 · 아쉬운 점 | 미션별 담당을 나누어 진행하고 테스트 결과를 공유한 점은 좋았다. 다만 미션 간 파일 의존성을 초기에 더 확인했으면 좋았을 것이다. |
