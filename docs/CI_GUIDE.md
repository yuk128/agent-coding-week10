# CI_GUIDE — 보안 CI 게이트 (Mission 5)

```
커밋        → 시크릿 스캔             (scanner/secrets.js)
풀 리퀘스트 → 코드 리뷰 · 공격 회귀 테스트 (npm test)
빌드        → 의존성 검사 · SBOM       (scanner/deps.js · sbom.js)
배포 전     → 한도 · 킬스위치 · 플레이북 확인
검사 실패   → 병합 · 배포 차단 → 수정 후 재실행
```

`node scripts/sec-ci.js` 가 위 검사를 한 번에 돌립니다.

- 우리 산출물: 통과(종료 코드 0)
- `node scripts/sec-ci.js --dir ai_sec` (AI 산출물): **실패(종료 코드 1)** 해야 합니다.
- 임계값(`THRESHOLDS`)은 한 곳에 모으고, 값마다 '왜 이 값인가'를 주석으로 남깁니다. 지키지 못할 임계값을 느슨하게 풀어서 통과시키지 않습니다.
- 자동화는 사람의 리뷰를 대체하지 않습니다 — 기계가 놓치는 것(권한 설계 같은 로직 취약점)은 사람이 봅니다.
