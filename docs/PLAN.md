# PLAN — 팀 계획 (Mission 0)

| 항목 | 내용 |
|---|---|
| 팀 이름 · 구성원 | 5조 / 이예은, 허소영 (2인) |
| 역할 교대표 | 2인 팀이라 한 명이 '진행(AI 에게 지시)', 다른 한 명이 '검증(공격해 보기 · 로그 읽기) + 기록 · 리뷰'를 맡고, 미션이 끝날 때마다 서로 바꾼다. M0 이예은 진행 / 허소영 검증·기록 → M1 허소영 진행 / 이예은 검증·기록 → M2 이예은 진행 → M3 허소영 진행 → M4 이예은 진행 → M5 허소영 진행 |
| 오늘의 목표 (점수 · 안전 기준) | 공개 시나리오 자동 평가 34/40 이상. 안전 기준: 공격 A1~A10 피해 0건, 정상 요청 B1~B9 전부 통과(오탐 0), V1~V7과 F 전부 통과, 시스템 프롬프트 점검(SP) 통과, npm test 통과 |
| 쓰는 AI 도구 · 사용 범위 | [claude] — 구현 초안, 경계 테스트 제안, 취약점 리뷰(근거는 사람이 확인). (AI 에 붙여 넣지 않는 것: 비밀 값 · 개인정보 · 미공개 코드 — 이 실습은 모두 가상이지만 습관을 연습한다) |
| 막히면 | 같은 시도 3번 실패 → 멈추고 원인 가설부터 |

## Mission 0 측정 기록
- `npm run eval:ai` (AI 가 만든 산출물) 점수: 17.55 / 40 (레드팀 3/6, 코드 1.45/9, 스캐너 0.65/7, 가드레일 9.82/12, 보안 관제 2.63/6)
- `npm run eval` (빈 템플릿) 점수: 4.65 / 40 (레드팀 1.65/6, 코드 0.68/9, 스캐너 0/7, 가드레일 1.09/12, 보안 관제 1.23/6)
- baseline 공격 관찰: 요청자 u1 인데 `get_order_status(ORD-1002)` 가 소유자 확인 없이 실행되어 u2 의 수령인·연락처(010-9876-5432)가 마스킹 없이 응답과 로그에 나감 (피해: CROSS_USER, PII_LEAK). 즉 소유자 확인(결정 계층)과 개인정보 마스킹(출력 계층)이 둘 다 없다.
- AI 산출물에서 가장 위험하다고 본 허점 3가지:
  1. 시스템 프롬프트에 비밀 값과 권한 우회 규칙이 들어 있음 (SP ✘) → 프롬프트가 유출되면 키·관리자 코드가 함께 노출됨 (LLM07)
  2. API 코드가 거의 방어되지 않음: V3 시크릿 0/4, V5 오류 노출 0/2, V6 클라이언트 값 신뢰 0/2, V7 토큰 위조 0/3, V2 IDOR 1/4 → 남의 주문 조회와 토큰 위조가 가능하고 비밀이 코드에 박혀 있음
  3. 운영 계층이 비어 있음: 킬스위치가 사유·담당자 없이 꺼지고 감사 기록이 없음(K-K5·K-K6), 탐지가 INJECTION_PROBE·ORDER_ENUMERATION·BUDGET_80 을 놓침 → 사고가 나도 알아채거나 멈출 수 없음
- 참고: 가드레일 82%인데 A7(리뷰 속 스크립트, OUTPUT_INJECTION)은 여전히 뚫림.
