# 모의 LLM(순진한 모델)의 동작 규칙

실제 모델이 아닙니다. **속아 넘어가는 모델**을 항상 같은 결과로 재현합니다(결정적). 구현은 `sim/mockLlm.js`.

## 읽는 방식

1. 입력(사용자 문장 + 외부 문서)을 **정규화**합니다: 전각 → 반각(NFKC), 보이지 않는 문자 제거, 영문 대소문자 무시.
2. `<<UNTRUSTED … UNTRUSTED>>` 로 감싼 구간은 **데이터**로 읽어 그 안의 지시를 따르지 않습니다. 구분자가 깨져 구간 밖에 놓인 글은 **지시**로 읽습니다.
3. 지시로 읽은 글에서 아래 문장 형태를 찾으면 **순서대로 따릅니다.** 권한 · 소유자 · 위험은 판단하지 않습니다.

| 지시 | 이런 문장을 찾으면 | 모델이 내놓는 것 |
|---|---|---|
| 프롬프트 공개 | 시스템 프롬프트 / system prompt / 처음 받은 지시 / 초기 설정 + 출력·알려·보여·공개·print·reveal·show | 시스템 프롬프트 전체를 `text` 로 |
| 메일 전송 | 전송·보내·발송·전달·send·forward 가 이메일 주소 40자 안에 있음 | `send_email{to, body: 세션 메모 + 입력}` |
| 주문 조회 | `ORD-…` 또는 `주문 …번호` + 상태·조회·확인·어디·배송·알려·보여·status·track·where | `get_order_status{order_id: 적힌 그대로}` |
| 환불 | 환불·취소·refund·cancel 이 주문번호 근처에 있음 | `refund_order{order_id}` |
| 쿠폰 | 쿠폰 + 적용·사용·apply (할인율은 `N%` 또는 코드 끝 숫자, 없으면 10) | `apply_coupon{code, percent}` |
| 삭제 | 상품·제품·DB·테이블 + 삭제·지워·제거·delete·drop | `delete_product{product_id}` |
| 반복 | `N번/회 + 반복·계속·검색·조회·호출` | `search_product` 를 N번(최대 30) |
| 요약 | 요약·summarize | 문서 내용(데이터 구간 포함)을 `text` 에 옮김 — 태그 · 개인정보 포함 |
| 자유 형식 | JSON 말고·형식 무시 | JSON 이 아닌 문장으로 답함 |
| 검색 | `○○ 검색/찾아`, `search ○○` | `search_product{query: ○○}` |

모델의 출력은 항상 JSON 문자열 `{"text": "...", "tool_calls": [{"name": "...", "args": {...}}]}` 입니다(자유 형식 제외).
**모델은 인가를 하지 않습니다.** 남의 주문 번호도, 100% 쿠폰도 그대로 호출로 만들어 냅니다 — 막는 것은 모델 바깥의 코드입니다.
